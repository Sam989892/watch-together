First launch shows an "unknown developer" warning (the app isn't code-signed yet) — on Mac right-click → Open; on Windows More info → Run anyway. Both are safe to dismiss. Windows: unzip, then run Watch Together.exe.

How to watch together

1

Both of you install the app and open the same video file in VLC (drag it in). Click ⚡ Set up VLC for me — it turns on VLC's remote control automatically.

2

You host: leave the server box blank and hit Create a new room. Share your room code — and, if you're on the same Wi‑Fi, your computer's local IP address.

3

Your friend joins: types your address in "Friend's server address", enters the room code, and clicks Join.

4

Press play. Every pause, seek and jump syncs both VLCs. Use the 🎙 button (or M) to talk, and 💬 to chat.
